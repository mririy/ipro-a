# Ай Про · IPROSCHOOL — сайт школы

Версия A полного сайта частной школы полного дня «Ай Про» (Ялта). Блоки связаны в историю одного дня в школе короткими подводками: время дня — 08:30 начинаются уроки, 12:40 время обеда, 14:30 после уроков, 18:00 пора домой — или короткая фраза («Здесь проходит день», «Взрослые рядом», «Пока вы на работе»). Рядом с подводкой — объёмная 3D‑картинка. Время дня показывается и в капсуле главы и «доходит» до нужного часа при прокрутке. Версия B без подводок — в репозитории `ipro-b`.

## Дизайн

Основа — как в версии B: каждая глава плавно перекрашивает страницу в свою палитру, на фоне — диагональные полосы и мягкое свечение, программы — цветные плитки с фото, списки — с мини-иконками в квадратах. Лист с новостями того же фона, что и страница: выезжая, он переводит тёмное видео в светлую главу. Сначала — телефон.

Оформление — современное, без приёмов 2012–2016 годов:

- кнопки плоские, без бликов, градиентов и объёмного края;
- плитки и фото без рамок, наклонов и полосок, отзывы — ровные карточки;
- тени мягкие, три уровня (`--sh-1 / --sh-2 / --sh-3` в `site.css`);
- заголовки с умеренной разрядкой (−0,03 em) и высотой строки 1,05, акцент — цветом одного‑двух слов, без маркера;
- без бегущей строки; появление блоков — короткий сдвиг на 18 px с проявлением, без поворотов;
- фирменный синий `#2A70B4` (чуть глубже прежнего), жёлтый `#FCC41C`, тёмно‑синий `#0A2C55`. Текст на синем и синий текст на светлом фоне проходят контраст WCAG AA (не ниже 4,5 : 1), мелкий текст — от 12 px.

Тексты подводок — в `LEADINS` в `gen/content.py`, объёмные картинки — в `assets/img/3d/`, палитры глав — `.pal-*` в начале `site.css`.

## Как опубликовать

Сайт статический, сборка не нужна. В настройках репозитория: **Settings → Pages → Deploy from a branch → `main` / root**. Файл `.nojekyll` отключает обработку Jekyll.

## Структура

```
index.html               страница целиком (собирается из gen/, см. ниже)
assets/css/site.css      стили и палитры глав
assets/js/site.js        перетекание цветов, сцены, окна, альбомы, форма, помощник
assets/data/news.json    новости и объявления (редактируются без сборки)
assets/img/              фото (*-sm.jpg — уменьшенные копии для телефонов), постеры видео
assets/img/3d/           объёмные картинки подводок
assets/video/            видео (tour.mp4 и hero_school.mp4 — главный экран)
assets/seq/              кадры 3D‑пролётов (особняк днём и ночью)
gen/                     генератор: тексты (content.py), разметка (build.py), фото и видео (media.py)
```

## Новости и объявления

Откройте `assets/data/news.json` на GitHub (значок карандаша) и добавьте запись:

```json
{
  "title": "День открытых дверей 15 ноября",
  "text": "Покажем классы, познакомим с педагогами. Начало в 11:00.",
  "tag": "Событие",
  "date": "2026-11-01",
  "image": "assets/img/september.jpg",
  "link": "#signup",
  "link_text": "Записаться",
  "pin": true
}
```

Обязательны только `title` и `text`. Записи с `"pin": true` идут первыми, остальные — от новых к старым по `date` (формат ГГГГ‑ММ‑ДД). В `link` можно указать раздел сайта (`#summer`, `#m-kindergarten` — сразу откроет программу детского сада) или внешнюю ссылку. Если удалить все записи, блок новостей скроется. Изменения видны сразу после сохранения файла — пересобирать сайт не нужно.

## Форма записи

Сейчас заявка без сервера: форма проверяет поля и предлагает отправить готовый текст в WhatsApp школы (а также Telegram, MAX или звонок). Чтобы заявки приходили на почту или в CRM, укажите адрес приёма в `index.html`:

```html
<form class="form" id="signupForm" novalidate data-endpoint="https://…">
```

На этот адрес уйдёт POST с JSON `{"name": "…", "age": "…", "phone": "…"}` (подойдёт Formspree, Getform, Яндекс Формы через вебхук или свой обработчик).

## Видео

На главном экране, пока видео загружается, показывается кадр‑заставка. На компьютере играет `assets/video/tour.mp4` (30 секунд обзора школы, около 2,6 МБ), на телефоне в вертикальном положении — вертикальное `assets/video/hero_school.mp4` (около 2,5 МБ). Когда будет вертикальная версия обзора, замените этот файл (и кадр‑заставку `assets/img/posters/hero_school.jpg`) или укажите другой путь в атрибуте `data-src-port`. Видео в блоках начинают грузиться, только когда до них доходит прокрутка. Все ролики сжаты в H.264 720p (`gen/media.py`), идут без звука, по кругу.

## Что заполнить данными школы

- «Сведения об образовательной организации»: полное наименование, ИНН, ОГРН, сканы лицензии и уставных документов (окно `#docs`).
- Видео «Администрация и дети» для главы «О школе» — его пока нет; когда появится, его можно добавить рядом с тремя видео (`ABOUT['videos']` в `gen/content.py`).
- Фото гостей «Встреч с интересными людьми» — сейчас вместо фото буквы‑монограммы.
- Педагоги по уровням обучения — информация в работе.
- Рейтинг и число отзывов Яндекс Карт (`REVIEWS` в `gen/content.py`) — сейчас 4,7 и 63 отзыва (октябрь 2026), обновляйте раз в несколько месяцев.
- Для превью в мессенджерах пропишите полный адрес картинки в `og:image`, когда будет известен домен.

## Правка текстов и сборка

Все тексты собраны в `gen/content.py`. Ответы на частые вопросы родителей — в помощнике «Вопросы?» (кнопка внизу справа), их тексты в `HELPER`. После правки:

```bash
pip install pillow
python3 gen/build.py .
```

Скрипт пересоберёт `index.html` (новости не трогает). Мелкие правки можно вносить и прямо в `index.html`, но следующая сборка их перезапишет.

## Доступность

Кнопка «Версия для слабовидящих» в подвале и меню включает контрастный режим с крупным текстом и без анимаций (выбор запоминается). При системной настройке «Уменьшить движение» анимации и автозапуск видео в блоках отключаются. Весь текст виден и без JavaScript.

Иконки — [Lucide](https://lucide.dev) (лицензия ISC, `gen/icons/LICENSE`), объёмные картинки — [Microsoft Fluent Emoji 3D](https://github.com/microsoft/fluentui-emoji) (лицензия MIT, `assets/img/3d/LICENSE-fluent-emoji.txt`), шрифт Onest (Google Fonts).
