# Ай Про · IPROSCHOOL — сайт школы

Версия A полного сайта частной школы полного дня «Ай Про» (Ялта) — «День под солнцем». Сайт рассказывает один школьный день: солнце из логотипа раскрывается в видео о школе, камера подлетает к 3D‑макету особняка, дальше главы идут по часам — 08:30 начинаются уроки, 12:40 время обеда, 14:30 после уроков, 18:00 пора домой — и небо страницы меняется от утра к закату и ночи. Всё листается только вниз, без бокового листания. Разделы, их порядок и тексты — как на нынешнем сайте. Версия B — в репозитории `ipro-b`.

## Дизайн

- Шрифты: Unbounded — заголовки, часы, цифры; Onest — текст. Оба из Google Fonts (лицензия OFL).
- Цвета школы: тёмно‑синий `#0A2C55`, синий `#2A70B4`, жёлтое солнце `#FCC41C`. Текст на всех фонах проходит контраст WCAG AA.
- Время дня — заголовок своей главы: крупные часы, солнце на дуге и короткая фраза. При прокрутке солнце идёт по дуге от места предыдущей главы, часы «доходят» до своего времени.
- Небо главы — две краски сверху вниз, вверху оно плавно перетекает из неба предыдущей главы. Где светлая глава сменяется тёмной (или наоборот), переход длиннее и проходит через светлый тон, а текст главы начинается после него. Краски задаются в `gen/build.py` — последний аргумент вызова `section(…)` у каждой главы.
- Неразрывные пробелы ставит сборка (`typo()` в `gen/build.py`): предлоги, союзы и числа не остаются в конце строки, «Ай Про» не разрывается.
- Мини-иконки — тонкие, без плашек ([Lucide](https://lucide.dev)).
- Окна программ, меню, сведения, альбомы и помощник открываются поверх страницы; разделы внутри окон переносятся на строки, а не листаются вбок.
- Сначала — телефон; на компьютере те же главы в две колонки.

## Как опубликовать

Сайт статический, сборка не нужна. В настройках репозитория: **Settings → Pages → Deploy from a branch → `main` / root**. Файл `.nojekyll` отключает обработку Jekyll.

## Структура

```
index.html               страница целиком (собирается из gen/, см. ниже)
assets/css/site.css      стили
assets/js/site.js        сцены прокрутки, окна, альбомы, форма, новости, помощник
assets/data/news.json    новости и объявления (редактируются без сборки)
assets/img/              фото (*-sm.jpg — уменьшенные копии для телефонов), постеры видео
assets/video/            видео (tour.mp4 и hero_school.mp4 — главный экран)
assets/seq/              кадры 3D‑макета: особняк утром (подлёт) и ночью (отъезд)
gen/                     генератор: тексты (content.py), разметка (build.py), фото и видео (media.py)
```

## Новости и объявления

Откройте `assets/data/news.json` на GitHub (значок карандаша) и добавьте запись:

```json
{
  "title": "День открытых дверей 15 ноября",
  "text": "Покажем классы, познакомим с педагогами. Начало в 11:00.",
  "tag": "Событие",
  "date": "2026-11-01",
  "image": "assets/img/september.jpg",
  "link": "#signup",
  "link_text": "Записаться",
  "pin": true
}
```

Обязательны только `title` и `text`. Записи с `"pin": true` идут первыми, остальные — от новых к старым по `date` (формат ГГГГ‑ММ‑ДД). В `link` можно указать раздел сайта (`#summer`, `#m-kindergarten` — сразу откроет программу детского сада) или внешнюю ссылку. Если удалить все записи, блок новостей скроется. Изменения видны сразу после сохранения файла — пересобирать сайт не нужно.

## Форма записи

Сейчас заявка без сервера: форма проверяет поля и предлагает отправить готовый текст в WhatsApp школы (а также Telegram, MAX или звонок). Чтобы заявки приходили на почту или в CRM, укажите адрес приёма в `index.html`:

```html
<form class="form" id="signupForm" novalidate data-endpoint="https://…">
```

На этот адрес уйдёт POST с JSON `{"name": "…", "age": "…", "phone": "…"}` (подойдёт Formspree, Getform, Яндекс Формы через вебхук или свой обработчик).

## Видео

На главном экране, пока видео загружается, показывается кадр‑заставка. На компьютере играет `assets/video/tour.mp4` (30 секунд обзора школы, около 2,6 МБ), на телефоне в вертикальном положении — вертикальное `assets/video/hero_school.mp4` (около 2,5 МБ). Когда будет вертикальная версия обзора, замените этот файл (и кадр‑заставку `assets/img/posters/hero_school.jpg`) или укажите другой путь в атрибуте `data-src-port`. Видео в блоках начинают грузиться, только когда до них доходит прокрутка, и играют, только пока видны. Все ролики сжаты в H.264 720p (`gen/media.py`), идут без звука, по кругу.

## Что заполнить данными школы

- «Сведения об образовательной организации»: полное наименование, ИНН, ОГРН, сканы лицензии и уставных документов (окно `#docs`).
- Фото и подписи блока «Внутри особняка» — `ABOUT['inside']` в `gen/content.py`; часть кадров взята из видеообзора школы, их стоит заменить фотографиями, когда они будут. Столовую школа просила не показывать.
- Фото гостей «Встреч с интересными людьми» — сейчас вместо фото буквы‑монограммы.
- Педагоги по уровням обучения — информация в работе.
- Рейтинг и число отзывов Яндекс Карт (`REVIEWS` в `gen/content.py`) — сейчас 4,7 и 63 отзыва (октябрь 2026), обновляйте раз в несколько месяцев.
- Для превью в мессенджерах пропишите полный адрес картинки в `og:image`, когда будет известен домен.

## Правка текстов и сборка

Все тексты собраны в `gen/content.py`, фразы к часам дня — в `LEADINS`. Ответы на частые вопросы родителей — в помощнике «Вопросы?» (кнопка внизу справа), их тексты в `HELPER`. После правки:

```bash
pip install pillow
python3 gen/build.py .
```

Скрипт пересоберёт `index.html` (новости не трогает). Мелкие правки можно вносить и прямо в `index.html`, но следующая сборка их перезапишет.

## Доступность

Кнопка «Версия для слабовидящих» в подвале и меню включает контрастный режим: белый фон, чёрный текст, крупнее шрифт, без анимаций и сцен прокрутки (выбор запоминается). При системной настройке «Уменьшить движение» сцены прокрутки заменяются неподвижными кадрами, видео в блоках не запускаются сами. Весь текст виден и без JavaScript.

Иконки — [Lucide](https://lucide.dev) (лицензия ISC, `gen/icons/LICENSE`), шрифты Unbounded и Onest (Google Fonts, OFL).
