# Ай Про · IPROSCHOOL — сайт школы

Версия A полного сайта частной школы полного дня «Ай Про» (Ялта). Блоки связаны в историю одного дня в школе: у блоков есть короткие подводки со временем дня — 08:30 начинаются уроки, 12:40 время обеда, 14:30 после уроков, 18:00 пора домой; у остальных — короткая фраза («Пока вы на работе», «А на каникулах», «Хотите к нам?»). Время дня показывается и в капсуле главы и «доходит» до нужного часа при прокрутке. Каждая глава плавно перекрашивает страницу в свою палитру. Версия B без подводок — в репозитории `ipro-b`.

Дизайн: плоские кнопки одной формы, одни и те же карточки и списки с мини-иконками во всех блоках, заголовки одним цветом (акцентное выделение — только в начале и в концепции), без наклонов, полос и свечений. Сначала — телефон.

Тексты подводок — в `LEADINS` в `gen/content.py`.

## Как опубликовать

Сайт статический, сборка не нужна. В настройках репозитория: **Settings → Pages → Deploy from a branch → `main` / root**. Файл `.nojekyll` отключает обработку Jekyll.

## Структура

```
index.html               страница целиком (собирается из gen/, см. ниже)
assets/css/site.css      стили и палитры глав
assets/js/site.js        перетекание цветов, сцены, окна, альбомы, форма, помощник
assets/data/news.json    новости и объявления (редактируются без сборки)
assets/img/              фото, постеры видео, фоны глав
assets/video/            видео (tour.mp4 — главный экран)
assets/seq/              кадры 3D‑пролётов (особняк днём и ночью)
gen/                     генератор страницы: тексты (content.py) и разметка (build.py)
```

## Новости и объявления

Откройте `assets/data/news.json` на GitHub (значок карандаша) и добавьте запись:

```json
{
  "title": "День открытых дверей 15 ноября",
  "text": "Покажем классы, познакомим с педагогами. Начало в 11:00.",
  "tag": "Событие",
  "date": "2026-11-01",
  "image": "assets/img/september.jpg",
  "link": "#signup",
  "link_text": "Записаться",
  "pin": true
}
```

Обязательны только `title` и `text`. Записи с `"pin": true` идут первыми, остальные — от новых к старым по `date` (формат ГГГГ‑ММ‑ДД). В `link` можно указать раздел сайта (`#summer`, `#m-kindergarten` — сразу откроет программу детского сада) или внешнюю ссылку. Если удалить все записи, блок новостей скроется. Изменения видны сразу после сохранения файла — пересобирать сайт не нужно.

## Форма записи

Сейчас заявка без сервера: форма проверяет поля и предлагает отправить готовый текст в WhatsApp школы (а также Telegram, MAX или звонок). Чтобы заявки приходили на почту или в CRM, укажите адрес приёма в `index.html`:

```html
<form class="form" id="signupForm" novalidate data-endpoint="https://…">
```

На этот адрес уйдёт POST с JSON `{"name": "…", "age": "…", "phone": "…"}` (подойдёт Formspree, Getform, Яндекс Формы через вебхук или свой обработчик).

## Видео на главном экране

На компьютере играет `assets/video/tour.mp4` (горизонтальное). На телефоне в вертикальном положении — вертикальное `assets/video/hero_school.mp4`. Когда будет вертикальная версия обзора, замените этот файл (и кадр‑заставку `assets/img/posters/hero_school.jpg`) или укажите другой путь в атрибуте `data-src-port`. Видео идёт без звука и без кнопок, по кругу.

## Что заполнить данными школы

- «Сведения об образовательной организации»: полное наименование, ИНН, ОГРН, сканы лицензии и уставных документов (окно `#docs`).
- Видео «Администрация и дети» для главы «О школе» — его пока нет; когда появится, его можно добавить рядом с тремя видео (`ABOUT['videos']` в `gen/content.py`).
- Фото гостей «Встреч с интересными людьми» — сейчас вместо фото буквы‑монограммы.
- Педагоги по уровням обучения — информация в работе.
- Для превью в мессенджерах пропишите полный адрес картинки в `og:image`, когда будет известен домен.

## Правка текстов и сборка

Все тексты собраны в `gen/content.py`. Ответы на частые вопросы родителей — в помощнике «Вопросы?» (кнопка внизу справа), их тексты в `HELPER`. После правки:

```bash
pip install pillow
python3 gen/build.py .
```

Скрипт пересоберёт `index.html` (новости не трогает). Мелкие правки можно вносить и прямо в `index.html`, но следующая сборка их перезапишет.

## Доступность

Кнопка «Версия для слабовидящих» в подвале и меню включает контрастный режим с крупным текстом и без анимаций (выбор запоминается). При системной настройке «Уменьшить движение» анимации отключаются автоматически. Весь текст виден и без JavaScript.
