# Ай Про (IPROSCHOOL) — сайт школы

Версия A полного сайта частной школы полного дня «Ай Про» (Ялта). Сайт рассказывает один день в школе: главы дня отмечены временем — 08:30 начинаются уроки, 12:40 время обеда, 14:30 после уроков, 18:00 пора домой. Время набрано крупными цифрами, под ним — тонкая шкала дня. Та же шкала идёт под шапкой на компьютере и тонкой линией слева на телефоне, пока идёт школьный день. Версия B — в репозитории `ipro-b`.

## Дизайн-система

- **Палитра школы:** тёмно‑синий `#0A2C55`, жёлтый `#FCC41C`, синий `#2F7BC4`. Дневные главы светлые (`#FFFFFF` / `#F4F7FB`, чередуются — так видна граница главы). Тёмно‑синий — только безопасность и запись. Жёлтый — только кнопки и метки времени.
- **Шрифт Onest:** 7 размеров — на телефоне 13 / 15 / 17 / 20 / 26 / 34 / 44 px (на компьютере крупные — 44 и 64), начертания 500 / 700 / 800, высота строки 1.1 у заголовков и 1.5 у текста. Акцент цветом — одно слово на первом экране.
- **Кнопки:** основная (жёлтая), второстепенная (обводка), текстовая (подпись со стрелкой).
- **Карточки:** медиа (фото + подпись снизу), информационная, факт, отзыв. Радиусы — только токены `--r-xl 36 / --r-l 28 / --r-m 20 / --r-s 14`, тени — три уровня `--sh-1 / --sh-2 / --sh-3`.
- **Брейкпоинты:** 600 / 1024 / 1280. Сначала — телефон: внизу панель «Записаться на 3 дня · Позвонить», «Вопросы» и «Меню» — в шапке.
- **Движение:** один короткий fade 300–350 мс, без масштабирования; при «Уменьшить движение» видео не запускаются сами.

Время глав — в `CLOCKS`, короткие подводки — в `EYEBROWS` (`gen/content.py`).

## Как опубликовать

Сайт статический, сборка не нужна. В настройках репозитория: **Settings → Pages → Deploy from a branch → `main` / root**. Файл `.nojekyll` отключает обработку Jekyll.

## Структура

```
index.html               страница целиком (собирается из gen/, см. ниже)
assets/css/site.css      дизайн-система и стили глав
assets/js/site.js        главы и шкала дня, видео, окна, альбомы, форма, помощник
assets/data/news.json    новости и объявления (редактируются без сборки)
assets/img/              фото (*-sm.jpg — уменьшенные копии для телефонов), постеры видео, ночной особняк
assets/video/            видео (tour.mp4 и hero_school.mp4 — первый экран)
assets/seq/estate/       кадры 3D‑макета особняка
gen/                     генератор: тексты (content.py), разметка (build.py), фото и видео (media.py)
```

## Новости и объявления

Откройте `assets/data/news.json` на GitHub (значок карандаша) и добавьте запись:

```json
{
  "title": "День открытых дверей 15 ноября",
  "text": "Покажем классы, познакомим с педагогами. Начало в 11:00.",
  "tag": "Событие",
  "date": "2026-11-01",
  "image": "assets/img/september.jpg",
  "link": "#signup",
  "link_text": "Записаться",
  "pin": true
}
```

Обязательны только `title` и `text`. Дата (`date`, формат ГГГГ‑ММ‑ДД) показывается в карточке, если заполнена. Записи с `"pin": true` идут первыми, остальные — от новых к старым. В `link` можно указать раздел сайта (`#summer`, `#m-kindergarten` — сразу откроет программу детского сада) или внешнюю ссылку. Если удалить все записи, блок новостей скроется. Изменения видны сразу после сохранения файла — пересобирать сайт не нужно.

## Форма записи

Сейчас заявка без сервера: форма проверяет поля и предлагает отправить готовый текст в WhatsApp школы (а также Telegram, MAX или звонок). Чтобы заявки приходили на почту или в CRM, укажите адрес приёма в `index.html`:

```html
<form class="form" id="signupForm" novalidate data-endpoint="https://…">
```

На этот адрес уйдёт POST с JSON `{"name": "…", "age": "…", "phone": "…"}` (подойдёт Formspree, Getform, Яндекс Формы через вебхук или свой обработчик).

## Видео

Первый экран: сначала показывается кадр‑заставка, видео грузится после страницы. На компьютере — `assets/video/tour.mp4` (30 секунд обзора школы, около 2,6 МБ), на телефоне — вертикальное `assets/video/hero_school.mp4` (около 2,5 МБ). У каждого зацикленного видео есть кнопка паузы. Видео в блоках начинают грузиться, только когда их видно. Все ролики сжаты в H.264 720p (`gen/media.py`).

## Что заполнить данными школы

- «Сведения об образовательной организации»: полное наименование, ИНН, ОГРН, сканы лицензии и уставных документов (окно `#docs`).
- Даты новостей в `assets/data/news.json`.
- Фото гостей «Встреч с интересными людьми» — сейчас вместо фото монограммы.
- Для превью в мессенджерах пропишите полный адрес картинки в `og:image`, когда будет известен домен.
- Рейтинг и число отзывов Яндекс Карт (`REVIEWS` в `gen/content.py`) — сейчас 4,7 и 63 отзыва (октябрь 2026).

## Правка текстов и сборка

Все тексты собраны в `gen/content.py`. Ответы на частые вопросы родителей — в помощнике «Вопросы» (кнопка в шапке), их тексты в `HELPER`. После правки:

```bash
pip install pillow
python3 gen/build.py .
```

Скрипт пересоберёт `index.html` (новости не трогает). Мелкие правки можно вносить и прямо в `index.html`, но следующая сборка их перезапишет.

## Доступность

Кнопка «Версия для слабовидящих» в подвале и меню включает контрастный режим с крупным текстом и без анимаций (выбор запоминается). При системной настройке «Уменьшить движение» анимации и автозапуск видео отключаются. Весь текст виден и без JavaScript.
